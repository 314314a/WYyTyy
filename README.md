# WYyTy - 個人中藥開單紀錄及佣金分析 (Android APK 自動生成 + PWA 離線版)

## 應用特點
- **安全密碼保護**：啟動時顯示專屬 WYyTy 解鎖背景，預設密碼為 `66668888`，可在設定自訂修改或切換開關。
- **靈活佣金選項**：提供 1仔、2仔、3仔 及新增的「其他（自訂佣金%）」，開單更靈活。
- **純淨離線儲存**：已全面移除測試範例數據按鈕，開局即為個人純淨帳本。
- **GitHub Actions 自動編譯 APK**：上傳至 GitHub 後，自動編譯生成 `WYyTy.apk` 手機安裝檔。

## 📱 下載 WYyTy.apk
1. 將解壓後的全部檔案上傳至你的 GitHub Repository。
2. 稍等約 1–2 分鐘 GitHub Actions 編譯完成後，即可在 GitHub 儲存庫首頁的檔案列表中直接點擊 **`WYyTy.apk`** 下載安裝！
